# run bash from docker image:
image-name es el nombre de la imagen de docker 
```bash
sudo docker run --rm -it --network host image-name bash 
```
# Configuración de nodos

**Importante:** Docker run crea una red virtual que prohibe a los nodos comunicarse entre sí. Se recomienda usar --network host como argumento en el comando docker run para usar la red de la máquina anfitrión.  

**Todos los comandos de esta sección se ejecutan dentro de la imagen de docker luego de correr docker run...**

En el nodo principal, para n nodos, el escritorio ssl_dir se usará para almacenar los archivos con las credenciales
```bash
Scripts/setup-ssl.sh n ssl_dir
```

El ssl_dir por defecto es Player-Data.
ssl_dir debe ser igual al que se encuentra en los archivos CONFIG y CONFIG.mine


## Transferencia de credenciales con scp
Configurar ssh local, darle enter a todo.
```bash
ssh-keygen -t rsa
```
### Por cada nodo ejecutar los siguientes comandos
En máquina remota ver ip con
```bash
ip addr
```


Enviar credenciales a máquina remota (se ejecuta desde nodo principal)
```bash
ssh-copy-id user@remote-ip
```

Para enviar archivos (se ejecuta desde nodo principal)
```bash
scp local-file user@remote-ip:remote-dir
```


## Ejecutar mascot-party.x (2 nodos)
